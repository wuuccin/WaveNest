## 0 结论

建议采用一条有依赖关系的技术路线：

原始飞行状态

|

v

20 数据校验过滤

| 输出可用状态、异常标记、短时补全状态

v

21 当前位置投影到规划航线

| 输出偏航距离、投影点、当前航段、航段内位置

+------------------+

v v

22 飞行进度定位 23 剩余航程估算

推荐的最小可行方案：

**数据校验过滤**：范围规则 + 时间连续性 + 运动学一致性 + MAD 鲁棒异常判别。

**短时丢包**：离线验证使用两端点之间的球面插值；实时运行使用速度/航向的短时航迹外推；超过允许间隔不补。

**偏航距离**：将当前位置与每个规划航段计算点到球面线段的最短距离，取最小值；同时返回最近航段和投影点。

**飞行进度**：复用 21 的最近航段和航段内投影距离，避免重复计算。

**剩余航程**：从投影点沿规划航线累加到上游归巢决策（E组功能10）给出的归巢落点；不把直线距离误当成航线剩余距离。

## 1 资料来源与用途

### 1.1 飞行状态字段与测试数据

• [OpenSky Network REST API 官方文档](https://openskynetwork.github.io/opensky-api/rest.html)

• 可作为输入字段定义的参考。

• 状态向量包含时间、WGS-84 经纬度、气压高度、地速、真航迹、垂直速度等字段。

• 文档明确了经纬度单位、地速单位、航向定义和垂直速度正负号。

• [OpenSky Network 官方 API 总览](https://openskynetwork.github.io/opensky-api/)

• 可用于获取公开的真实飞行轨迹样例。

• 项目数据若不能直接使用真实数据，可只借鉴字段结构，使用合成轨迹做验证。

### 1.2 异常检测与鲁棒统计

• [NIST：Detection of Outliers](https://itl.nist.gov/div898/handbook/eda/section3/eda35h.htm)

• 说明异常点识别、鲁棒方法和 modified Z-score。

• 推荐用中位数和 MAD 替代均值和标准差，降低野值对阈值估计的影响。

• [NIST：Median Absolute Deviation](https://itl.nist.gov/div898/software/dataplot/refman2/auxillar/mad.htm)

• 给出 MAD = median(|x - median(x)|) 的定义。

• 可用于速度残差、位置预测残差、垂直速度残差等特征。

### 1.3 地理距离与航段计算

• [Karney, Algorithms for geodesics](https://arxiv.org/abs/1109.4448)

• 给出椭球面测地线正解、反解等高精度算法。

• [GeographicLib 官方说明](https://geographiclib.sourceforge.io/geod.html)

• 提供 C/C++、Python、Java、JavaScript 等实现。

• 若后续精度要求提升，可将球面距离替换为 WGS-84 椭球测地线距离。

• [GeographicLib Python API](https://geographiclib.sourceforge.io/html/python/code.html)

• Inverse 可求两点距离和方位角。

• InverseLine/Position 可在一条测地线上按距离取点。

### 1.4 资料使用边界

• 公开资料用于定义字段、距离计算和鲁棒统计方法，不替代项目内部状态词和接口约定。

• 本组不负责模块一的格式级解析，也不负责模块二的船舶状态估计。

• 真实项目是否使用 WGS-84 椭球、球面半径、航路类型和单位，最终以项目统一口径为准。

## 3 功能 20：数据校验过滤

### 3.1 研究范围

• **序号**：20

• **功能名**：数据校验过滤

• **所属模块**：模块四 飞行任务监控

• **回答的问题**：当前收到的飞行状态是否可信；若出现野值或短时丢包，能否给出带质量标记的可用状态？

### 3.2 输入与输出

**输入来源**

• 上游飞行状态流或状态缓存。

• 同一 flight\_id 的近期历史状态点。

• 项目统一的飞行器运动边界和数据质量配置。

**输入粒度**

• 当前状态：单个飞行状态点。

• 历史状态：按时间排序的最近若干个状态点。

• 运行模式：实时流式或离线回放。

**输出**

建议输出原始值和清洗值并存：

cleaned\_state = {

flight\_id,

timestamp,

latitude,

longitude,

altitude,

ground\_speed,

track,

vertical\_rate,

state\_quality,

anomaly\_flags,

imputation\_method,

source\_timestamp

}

输出给模块四的监控展示、21 偏航距离计算和 22/23 的后续计算。

**边界**

• 不负责原始报文的字段解析、编码解码和格式级清洗。

• 不负责船舶或飞行器完整状态估计。

• 不使用规划航线判断“是否偏航”；路线偏差由 21 负责。

• 不对长时间无数据进行无依据预测。

• 不覆盖原始数据；清洗结果必须带有异常/补全标记。

### 3.3 算法设计

#### 3.3.1 总体策略

采用“硬规则先筛、运动学再判、鲁棒统计辅助、分级处理输出”的策略。

原始点

-> 字段存在性与取值范围检查

-> 时间顺序与重复点检查

-> 相邻点运动学一致性检查

-> 预测残差的 MAD 鲁棒判别

-> 正常 / 野值 / 短时丢包 / 长时缺失

-> 输出状态与质量标记

#### 3.3.2 基础校验

对每个点检查：

timestamp 是否存在，是否与上一点保持时间顺序。

经纬度是否在合法地理范围内。

高度、地速、垂直速度是否满足项目定义的物理范围。

航向是否可归一化到项目约定角度范围。

是否出现完全重复点、重复时间或关键字段全部为空。

这些属于语义级校验，不能替代模块一的格式级校验。

#### 3.3.3 运动学一致性

相邻点之间计算：

• delta\_t：时间间隔。

• distance\_obs：相邻经纬度的球面距离。

• speed\_implied = distance\_obs / delta\_t：由位置反推的平均地速。

• speed\_residual = |speed\_implied - ground\_speed|：位置与地速残差。

• acceleration\_est：相邻地速变化率。

• turn\_rate\_est：航向变化率，需先处理 0/360 度环绕。

• vertical\_speed\_implied：由高度差和时间间隔反推的垂直速度。

• vertical\_rate\_residual：反推垂直速度与上报垂直速度的差值。

判定原则：

• 单项超过项目边界时，标记对应异常原因。

• 多项同时异常时，提高异常等级。

• 不能因为一个字段为空就直接丢弃整条状态；应按字段能力降级。

#### 3.3.4 野值判别

对以下残差序列使用滑动窗口 MAD：

• 位置预测残差。

• 速度残差。

• 垂直速度残差。

• 必要时的航向变化残差。

位置预测可采用上一有效状态的短时匀速模型：

predicted\_position =

从上一有效位置沿上一有效航向前进 ground\_speed \* delta\_t

position\_residual =

distance(observed\_position, predicted\_position)

改进判据：

modified\_score =

scale\_factor \* (residual - window\_median) / window\_MAD

当 MAD 为零或窗口样本不足时，退回硬规则或相邻点一致性判定，不能直接做除零计算。

#### 3.3.5 短时丢包处理

分为离线回放和实时流式两种情况：

**离线回放**

• 已知丢包区间两端的有效点。

• 水平位置沿两端点之间的球面航线插值。

• 高度采用时间线性插值。

• 地速可采用线性插值或邻域稳健值。

• 航向采用圆周角插值，不能直接普通线性插值跨越 0/360 度。

**实时流式**

• 只有最近一个有效点时，按最近有效地速、航向做短时外推。

• 每次外推都累计“已连续外推时长”。

• 超过允许的最大外推时长后停止补点，输出缺失状态。

• 外推结果必须标记 imputed 或项目对应状态词，不能伪装成原始观测。

#### 3.3.6 分级处理

建议输出以下处理结果，具体状态词沿用项目既定口径：

|  |  |  |
| --- | --- | --- |
| **情况** | **处理** | **是否参与后续计算** |
| 正常点 | 原样通过 | 参与 |
| 可疑但未确认野值 | 保留原值并标记 | 按项目策略 |
| 确认野值 | 用邻域/预测值替换清洗值，保留原始值 | 使用清洗值 |
| 短时丢包 | 插值或短时外推 | 使用补全值并带标记 |
| 长时间缺失 | 不补，输出缺失 | 不参与距离和进度计算 |

### 3.5 验证方式

**数据**

真实轨迹回放：使用项目历史数据或公开飞行轨迹字段结构。

合成正常轨迹：设置不同直线、转弯、爬升、下降场景。

注入异常数据：

• 经纬度突跳。

• 高度突跳。

• 速度异常。

• 时间乱序。

• 单点野值。

• 短时连续丢包。

• 长时连续丢包。

**指标**

• 野值检测 Precision、Recall、F1。

• 清洗后位置 MAE、P95 误差。

• 补全点位置误差和高度误差。

• 清洗后运动学违规率。

• 实时外推延迟和停止补全是否符合边界。

• 原始点、清洗点、补全点是否可追溯。

**重点场景**

• 直线匀速。

• 匀速转弯。

• 爬升或下降。

• 航向跨越 0/360 度。

• 连续两端存在有效点的短时缺口。

• 只知道缺口前状态的实时外推。

### 3.6 待定项

• 项目中的“状态词”以及质量等级名称。

• 地速、空速、航向、航迹角的具体口径。

• 是否允许用清洗/补全点驱动 21～23。

• 外推持续时间和长缺口判定标准。

• 野值是替换、删除，还是只标记不替换。

• 高度使用气压高度还是几何高度。

• 实时模式是否允许等待下一点，以便使用两端点插值。

## 4 功能 21：偏航距离计算

### 4.1 研究范围

本功能算无人机相对规划航线的几何偏航距离，不涉及会面意图/船侧偏差（属E组功能17）。

• **序号**：21

• **功能名**：偏航距离计算

• **所属模块**：模块四 飞行任务监控

• **回答的问题**：当前飞行位置到规划航线的最短垂直距离是多少，最近的是哪一个航段？

### 4.2 输入与输出

**输入来源**

• 20 输出的有效或允许使用的当前飞行状态点。

• 上游规划模块提供的有序航点数组。

**输入粒度**

• 当前飞行位置：单点经纬度。

• 规划航线：一个有序航点序列；相邻航点构成一个航段。

**输出**

deviation\_result = {

deviation\_distance,

nearest\_segment\_index,

nearest\_waypoint\_before,

projection\_point,

along\_track\_distance,

cross\_track\_side,

calculation\_quality

}

其中 deviation\_distance 是点到规划航线的最短距离，projection\_point 是航段内部投影点或最近端点。

**边界**

• 只计算几何偏航距离，不判断是否触发告警。

• 不负责航线重规划。

• 不负责高度层偏差；除非项目明确要求，否则本功能只处理水平面经纬度距离。

• 规划航段默认按球面大圆弧处理；若项目使用恒向线或三维航段，需要另行确认。

### 4.3 算法设计

#### 4.3.1 选型

采用“点到每个球面线段的最短距离，取全局最小值”。

选择原因：

• 直接符合“最短垂直距离”的定义。

• 能同时返回最近航段、投影点和航段内位置，供 22 和 23 复用。

• 航段数量通常有限，复杂度为 O(number\_of\_segments)，实现和验证简单。

• 后续可把球面距离替换成 GeographicLib 的 WGS-84 椭球距离，不改变上层接口。

#### 4.3.2 球面距离

令纬度、经度转为弧度，球面半径为 EARTH\_RADIUS。

两点间角距离可用 Haversine：

a = sin²((lat2 - lat1) / 2)

+ cos(lat1) \* cos(lat2) \* sin²((lon2 - lon1) / 2)

central\_angle = 2 \* asin(sqrt(a))

distance = EARTH\_RADIUS \* central\_angle

#### 4.3.3 点到球面线段

对当前位置 P 和航段端点 A -> B：

计算 A -> P 和 A -> B 的球面角距离。

计算从 A 出发到 P、到 B 的初始方位角。

计算球面大圆上的横向角距离：

cross\_track\_angle =

asin(sin(angle\_AP) \* sin(bearing\_AP - bearing\_AB))

计算沿航段方向的带符号距离：

along\_track\_angle =

atan2(

sin(angle\_AP) \* cos(bearing\_AP - bearing\_AB),

cos(angle\_AP)

)

进行线段边界判断：

• 若 along\_track\_angle < 0，最近点是 A。

• 若 along\_track\_angle > angle\_AB，最近点是 B。

• 否则，最近点在航段内部，垂直距离为：

deviation\_distance =

EARTH\_RADIUS \* abs(cross\_track\_angle)

对全部航段取最小距离。

注意：

• 角度运算前要统一到弧度。

• 经度差要处理跨越 ±180 度的情况。

• asin 入参需要进行数值截断，防止浮点误差略超 [-1, 1]。

• 若航点重复或航段长度接近零，跳过该航段或按端点处理。

#### 4.3.4 最近航段的连续性

当多个航段距离非常接近时，单纯取最小值可能在相邻航段之间抖动。可增加：

• 上一时刻最近航段索引。

• 航段切换迟滞参数。

• 沿航线进度的单调性约束。

• 仅在新航段优势超过切换界限时切换。

这些策略用于稳定结果，不改变几何距离定义。

### 4.4 参数与阈值清单

|  |  |
| --- | --- |
| **参数名** | **含义** |
| EARTH\_RADIUS | 球面距离计算使用的地球半径 |
| ANGLE\_EPSILON | 角度比较的数值容差 |
| DEGENERATE\_SEGMENT\_LIMIT | 近零长度航段判定界限 |
| SEGMENT\_SWITCH\_MARGIN | 最近航段切换迟滞量 |
| MAX\_ROUTE\_SEGMENT\_CANDIDATES | 可选的候选航段数量上限 |
| LONGITUDE\_WRAP\_POLICY | 经度跨越 ±180 度时的归一化规则 |

### 4.5 验证方式

**基础几何用例**

• 点在线段上：偏航距离接近零。

• 点在线段左侧/右侧：距离方向正确。

• 最近点为航段起点。

• 最近点为航段终点。

• 点位于两个航段连接处。

• 航线跨越经度 ±180 度。

• 极短航段和重复航点。

**指标**

• 与人工构造真值的绝对误差。

• 与 GeographicLib/WGS-84 结果的差异。

• 最近航段识别准确率。

• 连续轨迹上的距离抖动次数。

• 单条轨迹全量计算耗时。

**建议验收图**

• 规划航线、当前位置、投影点三者的地图示意图。

• 偏航距离随时间变化曲线。

• 球面算法与椭球算法的误差对比曲线。

### 4.6 待定项

• 项目要求的“球面距离”是否明确指定半径。

• 航段采用大圆弧、恒向线还是其他航线表示。

• 是否要把航段方向纳入偏航距离的正负号。

• 是否需要同时输出水平偏航和高度偏差。

• 规划航线是否保证无重复航点、无自交和按飞行顺序排列。

## 5 功能 22：飞行进度定位

### 5.1 研究范围

• **序号**：22

• **功能名**：飞行进度定位

• **所属模块**：模块四 飞行任务监控

• **回答的问题**：当前飞行器位于哪个航点附近、哪个规划航段，以及在该航段上前进了多远？

### 5.2 输入与输出

**输入来源**

• 20 输出的当前有效位置。

• 21 输出的最近航段、投影点和沿航段距离。

• 规划航线的有序航点数组。

**输入粒度**

• 当前状态：单点。

• 规划航线：有序航点序列。

• 可选历史状态：上一时刻航段和进度，用于稳定切换。

**输出**

progress\_result = {

current\_waypoint\_index,

current\_segment\_index,

segment\_progress\_distance,

route\_progress\_distance,

route\_progress\_ratio,

projection\_point,

progress\_quality

}

### 5.3 算法设计

飞行进度依附 21，不再单独重新计算点到航线距离。

从 21 得到最近航段 segment\_i = (W\_i, W\_{i+1})。

得到当前位置在该航段上的投影点 Q。

计算：

segment\_progress\_distance = distance(W\_i, Q)

route\_progress\_distance =

cumulative\_route\_distance\_before\_segment\_i

+ segment\_progress\_distance

用航段边界、航点到达判据判断当前航点：

• 距离 W\_i 更近且尚未越过航段起点时，认为位于航点 W\_i 附近。

• 接近或越过 W\_{i+1} 时，切换到下一个航段。

• 航点到达判据由项目阈值控制，不能直接把“最近点”当成“已到达”。

计算进度比例：

route\_progress\_ratio =

route\_progress\_distance / total\_route\_distance

应对抖动：

• 保存上一时刻航段和进度。

• 设置航段切换迟滞。

• 对进度增加非回退约束，但在返航、重规划或任务重置时清空历史约束。

### 5.4 参数与阈值清单

|  |  |
| --- | --- |
| **参数名** | **含义** |
| WAYPOINT\_REACHED\_DISTANCE | 航点到达判定距离 |
| SEGMENT\_SWITCH\_MARGIN | 航段切换迟滞量 |
| PROGRESS\_BACKTRACK\_TOLERANCE | 允许的进度小幅回退量 |
| PROGRESS\_RESET\_CONDITION | 重规划、返航等导致进度重新计算的条件 |
| MIN\_SEGMENT\_LENGTH | 可参与进度计算的最小航段长度 |
| PROGRESS\_QUALITY\_POLICY | 原始、清洗、补全状态参与进度输出的策略 |

### 5.5 验证方式

• 当前位置分别位于航段起点、中点、终点。

• 轨迹经过航点但有定位噪声。

• 当前位置在相邻航段交界处来回抖动。

• 轨迹存在短时丢包和补全点。

• 航线中存在短航段、重复航点。

• 返航或规划航线更新后重新定位。

指标：

• 当前航段识别准确率。

• 航点到达判定准确率。

• 进度距离 MAE。

• 进度比例是否单调。

• 航段切换抖动次数。

• 重规划后恢复时间。

### 5.6 待定项

• “当前航点”是最近航点、上一个已通过航点，还是下一个目标航点。

• 航点到达的项目状态词。

• 返航时是否沿用原路线，还是切换为新的归巢路线。

• 航线更新时历史进度是否保留。

• 是否允许补全点推动航点切换。

## 6 功能 23：剩余航程估算

### 6.1 研究范围

**功能定位：**消费方，消费上游归巢决策（E组功能10）给出的归巢落点及所在航段信息，并据此计算剩余距离。

• **序号**：23

• **功能名**：剩余航程估算

• **所属模块**：模块四 飞行任务监控

• **回答的问题**：从当前沿规划路径的位置，到上游归巢决策（E组功能10）给出的当前归巢落点还剩多远？

### 6.2 输入与输出

**输入来源**

• 20 输出的当前有效位置。

• 21/22 输出的投影点、当前航段和路线进度。

• 规划航线。

• 上游归巢决策（E组功能10）提供的归巢落点。

**输入粒度**

• 当前投影状态：单点。

• 规划航线：有序航点数组。

• 归巢落点：单点。

**输出**

remaining\_route\_result = {

remaining\_distance,

current\_segment\_index,

destination\_point,

route\_end\_distance,

calculation\_quality

}

**边界**

• 估算的是沿当前规划路径的剩余距离，不是当前位置到落点的直线距离。

• 不估算剩余时间、油耗、电量或到达概率。

• 不负责决定归巢落点。

• 若没有可靠的规划路径，只能输出不可计算/低质量状态，不能用直线距离冒充航程。

### 6.3 算法设计

将上游归巢决策（E组功能10）给出的归巢落点视为规划路径终点的附加点。若当前投影点位于航段 i：

remaining\_distance =

distance(projection\_point, W\_{i+1})

+ sum(distance(W\_j, W\_{j+1}))

for j = i+1 ... n-1

+ distance(W\_n, landing\_point)

若当前投影点已经位于归巢落点所在的附加航段，则只累加投影点到落点的剩余距离。

实现步骤：

复用 21 的 projection\_point 和最近航段。

预先计算规划航线的累计距离数组，避免每次重复累加。

将归巢落点作为末端航点，计算末端连接距离。

处理当前位置超出航线起点/终点的情况：

• 在起点前：按项目策略从起点开始或输出低质量。

• 超过终点：使用当前位置到归巢落点的直接末段，或输出超航线状态。

输出距离和计算质量，不输出没有依据的 ETA。

### 6.4 参数与阈值清单

|  |  |
| --- | --- |
| **参数名** | **含义** |
| LANDING\_POINT\_VALIDITY\_RULE | 归巢落点有效性判定 |
| ROUTE\_END\_CONNECTION\_POLICY | 末端航点到归巢落点的连接方式 |
| OFF\_ROUTE\_REMAINING\_POLICY | 当前位置明显离开航线时的处理方式 |
| PROJECTION\_VALIDITY\_LIMIT | 投影结果可参与剩余航程计算的界限 |
| DISTANCE\_RECALCULATION\_POLICY | 航线或落点变化时的累计距离更新规则 |
| REMAINING\_DISTANCE\_PRECISION | 输出距离精度 |

### 6.5 验证方式

• 当前点在首个航段、中间航段和末端航段。

• 归巢落点恰好等于最后航点。

• 归巢落点位于最后航点之后。

• 当前点偏离航线但仍能投影到航段。

• 归巢落点缺失、越界或发生变化。

• 规划航线重新下发。

指标：

• 与手工累计距离的绝对误差。

• 与 GeographicLib 参考结果的误差。

• 归巢落点变化后的更新正确性。

• 航线前进过程中剩余距离是否总体下降。

• 对明显离线点是否正确输出低质量/不可计算状态。

### 6.6 待定项

• “剩余航程”是否始终沿规划航线，还是返航时改用直达落点。

• 上游归巢决策（E组功能10）提供的落点是否可能实时更新。

• 超出规划航线时使用哪种策略。

• 是否需要按三维空间距离计算。

• 落点及所在航段由上游随决策一并给出。

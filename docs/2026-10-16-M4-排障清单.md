## 五、track→detect 接线链（API 已全部存在，缺口仅编排类）

```
UavTelemetry msg                                         // 订 TopicName.DATA_UAV_TELEMETRY（C1 源头缺）
 → TelemetryService.acceptState(msg) : TelemetryState    // 彭紫情 monitor.ingest；另有 accept(msg) 归一化出口
 → if (!state.geometryUsable()) 丢帧                      // 字段置 null 的脏帧不进检测
 → FlightTracker.measure(state, route, landing, returningOrOffRoute)
       : FlightTracker.Measurement                       // 彭紫情 monitor.track；route/landing 来源缺(C4)
       内含 record Measurement(RouteMeasurement.Projection, Progress, Remaining)
 → OfftrackDetector.feed(m.projection(), state.timestamp()) : DetectionResult   // 我方 algo.detection
 → AlertRecorder.record(result, msg.uavId(), orderId) : AlertEvent（或 null）   // 我方 monitor.alert
 → 下游 MQ alert.event / WS AlarmFrame / alert 表        // C5，16 号
```
要点：`TelemetryState.flightId()` 即 `telemetry.uavId()`；`clean()` 对 null/blank uavId
**抛 IllegalArgumentException**，编排类必须 try-catch 防毒消息打死监听线程；检测无告警的帧要调
`AlertRecorder.resolve(...)` 完成清除复位。

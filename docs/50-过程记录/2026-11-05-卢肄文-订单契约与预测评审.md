# 2026-11-05 卢肄文 订单契约与预测评审记录

## 一 任务与结论

本次承担 11-05 任务清单第一批的订单侧契约 v2 与预测链路评审 6 条。两项任务均已完成并合入 `develop`。订单契约统一了货物所在巢、优先级取值序与预计送达时刻的入出口径；预测链路按异常类型与数据可信度收口了 AIS 接入、参考线重建、低速航向与哨兵值四条边界。

## 二 订单侧契约 v2

- 订单提交请求新增货物所在巢字段，排在第六个分量，同时保留五参旧构造。旧构造表示未指定货巢，既有调用点不需要同步修改。字段可空，空值表示取离船最近巢。
- 期望送达时间明确为可空字段。字段层已允许为空，但受理判定仍要求期限非空，当前不填期望时间仍会转人工，解除该依赖留给第二批的期限系统计算。
- 船标识、货型、货巢在记录体的紧凑构造器内统一去首尾空白，全空白转空值。归一放在构造器内，保证基本校验、判定链与订单事件落库看到的是同一份归一值。
- 货型长度上限为六十四，与数据库列宽一致。超长在入口拦截并回货型过长原因码，避免库层静默截断或把一次下单变成服务端错误。
- 订单优先级新增取值序，普通为一、加急为二、紧急为三。取值序不覆写比较器，避免枚举声明顺序变化时队列取单次序静默反转。
- 订单提交响应新增预计送达时刻，来源唯一为订单表的预计送达列，取不到填空，不在本层自行计算 ETA。保留七参旧构造，语义为未算出。
- 新增货物到巢端点，方法为 POST，路径按订单号提交。端点幂等：只把未就绪翻为已就绪，已是已就绪直接跳过并返回未改动；已装机、已交付、已回收、灭失四种后置状态拒绝回退；查无货物记录不新建。端点只改货物状态，不推进订单状态。
- 货物所在巢已透传到判定请求的订单对象。落库依赖张睿哲的订单表迁移，迁移合入后不需要再改本层代码。

## 三 预测链路评审

- AIS 接入异常处置：改前只捕获非法参数异常，其余运行时异常直接抛出。消息队列缺省允许重投，一条毒帧会无限重投并堵住整条 AIS 队列。现在按「再处理一次会不会有不同结果」二分：非法参数异常属于契约内的脏观测，丢弃本帧并带异常栈记警告；其余运行时异常记错误并转死信，一次进死信不重投。
- 空消息保护：日志字段在进入异常处理前完成空安全取值。改前空消息会在异常处理块内再次触发空指针，把丢一帧升级为消费中断。
- 参考线重建失败：参考线重建返回空时，本拍不再出预测。改前会继续用已经走完的线出预测，得到一版看着正常、实际冻结的点列，下游无法区分它和船真的停住。
- 低速航向门：船速低于一节时，自报航向被位置噪声淹没，属于随机量，不再用它建线。速度恢复后下一拍自然重建。
- AIS 哨兵值：拒绝不可用航速、越界航向与不可用航向。不可用航速会让一秒位移达到五十二米，越界航向与不可用航向不能进入建线。

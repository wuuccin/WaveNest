## 3 模块功能细化分配

**任务二：模块功能细化。**

| 模块 | 负责人 | 核心职责 |
|---|---|---|
| 第一模块 数据采集 | 杨添爻 | 五路数据源接入、解析、清洗分层与统一投递的常驻数据源头 |
| 第二模块 调度引擎 | 卢肄文 | 唯一调度主控：接单、候选展开、剪枝、择优、占位、起飞时刻回填、飞行中重调度、返航复核 |

| 第六模块 数据库与缓存 | 张睿哲 | 统一数据底座：落库、缓存、坐标归一与一致性保障 |

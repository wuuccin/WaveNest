# 2026-11-09 / 11-10 模拟数据两天任务

## 0. 目标与边界

- 目标：六个人各产出一套**可独立运行、可独立评审**的模拟数据，覆盖基础场景 + 一个变体场景。
- 数据量要大：每套按 **4 小时、1 Hz、4 架无人机**生成；全量总行数目标 **≥ 100 万行**。
- **PR 只在第二天提**；第一天只做、只本地提交，不提 PR、不 push。
- 不改业务代码，只动 `testdata/mock/`。
- 互不等待：不等 `_baseline`、不等生成器、不等别人合并。现有 `016` 中心线、`003` 机巢、`004` 桥位就是基线。
- 你两天都只调系统；第二天末尾只看 PR、做合并。

## 4. 第一天（11-09）：只做基础套，不提 PR

每人做三件事：

1. 写 `generate.py`：读 `scenario.yaml`，支持 `--profile sample|full`，输出上表 9 个文件。
2. 生成基础套全量：`--profile full`，4 小时、1 Hz、4 架机；本地跑通，记录行数/大小到 `manifest.json`。
3. 提交 sample（5 分钟）+ `generate.py` + `manifest.json` + `README.md` 草稿；**本地 commit，不 push、不提 PR**。

基础套参数：

- **卢 `normal_straight`**：船直行 4 h，无扰动；订单 2.5 kg 药品、`NEST-01`、`cargoReadyAt=t0+300s`。验收：船位离中心线 ≤80 m，1 Hz，时间戳单调。
- **宋 `uav_low_battery`**：UAV-02 电量 60%→18%，`t0+300s` 写 `LOW_BATTERY`；4 架机、2 巢。验收：电量单调、状态转移合法。
- **张 `cargo_late`**：`cargoReadyAt=t0+600s`；60 单里至少 10 单跨到货窗口。验收：`WAIT_CARGO` → `DISPATCHING`，到货前无派机。
- **彭 `wind_gust`**：`t0+600s` 阵风 14 m/s，风向 90°；4 h 内至少 2 次阵风。验收：阵风事件、返航决策、订单重排。
- **罗 `bend_turn`**：`t0+120s` 船 357°→327°，4 h 内多次弯道。验收：所有点在河面，转向角/时间对。
- **杨 `ui_replay`**：60 s 起，六类帧 `ship_traj / drone_state / rendezvous / alarm / order_state / plan_track`；全量 4 h。验收：时间戳单调、字段齐全、能播完。

第一天结束标准：基础套 `--profile full` 能生成、`sample` 能提交、`README` 有运行命令；**没有 PR**。

## 5. 第二天（11-10）：补变体 + 提 PR

每人做四件事：

1. 加变体套 `scenario.yaml` 与参数，复用第一天的 `generate.py`。
2. 生成变体全量，更新 `manifest.json`。
3. 写 `README.md`：两套场景、seed、运行命令、expected、自检结果。
4. push 分支，开**一个 PR**，两套一起提。

变体套参数：

- **卢 `speed_change`**：`t0+180s` 船速 4.12→2.5 m/s；4 h 内多次变速。验收：ETA 后移、预测/会面跟着变。
- **宋 `uav_comm_loss`**：UAV-01 在 `t0+240s` 起断遥测 20 s；至少 3 次断链。验收：状态保持/返航、订单不丢。
- **张 `order_burst`**：`t0` 与 `t0+60s` 各来 5 单，`NEST-01` 容量 1；验收：一单派、其余排队，闸门生效。
- **彭 `wind_shift`**：`t0+300s` 风向 90°→180°，风速不变；至少 2 次反转。验收：航迹/返航按机型风限。
- **罗 `turn_sharp`**：`t0+120s` 在南昌桥附近转 45°；至少 3 次急转。验收：不压岸、不穿桥。
- **杨 `ui_alarm_replay`**：`alarm + order_state + plan_track` 三类帧，4 h；验收：告警出现、状态变化、航迹刷新。

## 6. PR 规则

- 一人一分支：`testdata/<姓名>-<主题>`；一人一个 PR，两套一起提。
- PR 只放 `testdata/mock/<base>/` 与 `testdata/mock/<variant>/` 两个文件夹；**不放全量 CSV**，只放 `generate.py`、`sample/`、`manifest.json`、`README.md`。
- PR 标题：`testdata: add <base> and <variant> scenarios`。
- PR 描述写清：两套场景、`seed`、`--profile full` 命令、行数/大小、自检结果。
- 每个 PR 指定 1 名横向 reviewer（卢看船、宋看机、张看订单、罗看几何、杨看帧）+ 你；reviewer 先过，你合并。

## 1 模块定位与边界

本模块是 M5 的**可视化子终端**：面向答辩评委与演示场景，把算法层的产出翻译成图层与面板，是「看起来成体系」的关键。

本模块的「算法」不是自己写调度算法，而是**把算法层的输出翻译成图层**。边界与形态选型与 `35-M5-终端交互` 一致（同一套 Web 工程、同一套地图组件与请求封装）。

---

## 2 大屏图层与面板

| 图层或面板 | 内容 |
|---|---|
| 地图底图 | 沿江航道 2D 电子地图，标出机巢位置、禁飞区、桥梁净空区、应急迫降点 |
| 船舶图层 | 实时船位 ＋ 航向箭头；**预测轨迹用虚线**，不确定性用半透明置信椭圆表示 |
| 无人机图层 | 实时机位 ＋ 规划航迹实线；按飞行阶段着色区分（去程、末段交接、返程、兜底盘旋） |
| 会面点图层 | 动态会面点用**十字准星**标记，随预测刷新而动；锁定后高亮 |
| 告警图层 | 触发兜底事件的实体在地图上**闪烁红色**并弹出提示框，与后台事件日志联动 |
| 统计面板（侧边） | 「传统方案与本方案」能耗对比柱状图；当前在飞任务数、接单成功率；轨迹预测误差曲线（对应数据回流的 ★★ 卖点） |
| 时间轴回放 | 底部时间轴可拖动，回放任意一段历史任务 |

一条设计取向：会面点用十字准星并随预测刷新而移动，是为了让「先预测再见面」这个核心卖点**在画面上看得见**，而不是靠讲解。

## 3 算法输出到画面的映射

这是前端与算法同学对接时最容易扯皮的地方，按下表约定数据格式。

| 算法层输出 | 前端怎么画 |
|---|---|
| 船舶未来轨迹 ＋ 不确定性（M2 调度引擎） | 虚线 Polyline ＋ 半透明置信椭圆（椭圆长短轴来自预测**标准差**：`a = 2·sigmaAlong`、`b = 2·sigmaCross`，旋转角 `courseDeg`，见 `22` §4、`80` §2.3） |
| 会面点 (X, Y, Time)（M3，组合级产物） | 十字准星 DivIcon，坐标随刷新平移；锁定后加边框高亮 |
| 规划航迹（M3 生成、M2 确认下发） | 实线 Polyline，按去程、末段、返程分段着色 |
| 兜底事件（横切机制）与 6b 意图变更（M3） | 触发实体红色闪烁 ＋ 右侧事件流追加一条 |
| 仿真框架能耗对比、实际能耗、偏差、预测误差（数据回流） | ECharts 柱状图与折线图，作为大屏侧边统计面板 |

## 4 WebSocket 消息

统一格式：

```json
{ "type": "...", "data": { ... } }
```

`type` 决定前端走哪套渲染逻辑。四类消息与渲染对象：

| `type` | 数据内容 | 渲染 |
|---|---|---|
| `ship_traj` | 船舶未来轨迹点列 ＋ 不确定性 `cov` | 虚线轨迹 ＋ 置信椭圆 |
| `drone_state` | 无人机位置、电量、飞行阶段 | 机位图标与状态卡 |
| `rendezvous` | 订单、会面点经纬度、是否锁定 | 十字准星，锁定后高亮 |
| `alarm` | 级别、类型、目标、提示语 | 实体闪烁 ＋ 事件流追加 |

字段名在开工前需与后端、算法层拉齐一次（见 `22-接口契约` §7）。

## 5 时间轴回放

底部时间轴可拖动，回放任意一段历史任务。答辩时可拖回去重放：

> 船突然变向 → 识别 6b → 原机放弃会面 → 返航迫停并回收货物 → 订单重入队

它是主链路出问题时的兜底，也是回答「刚才那段能再放一遍吗」这类追问的手段。回放数据取 `/api/replay/{taskId}`。

---

## 6 技术选型

与 `35-M5-终端交互` §6 共用一套：Vue 3 ＋ Vite、Leaflet ＋ 天地图或 OpenStreetMap、WebSocket（SSE 或轮询降级）、ECharts、Pinia。**不上 3D**——现场 2D 更稳。

---

## 7 部署方案与现场兜底

| 项 | 方案 |
|---|---|
| 正式部署 | 前端打包为静态文件，与后端 API 一起部署到一台云服务器，分配公网网址，评委现场输入即可打开 |
| 现场兜底 | 比赛现场网络可能不稳，提前把后端与前端同时部署到现场一台笔记本或 mini 主机，走局域网，断外网也能跑 |
| 底图离线 | 在线地图瓦片依赖外网，必须**提前把沿江作业区的瓦片下载成离线包**，现场无外网时切本地瓦片，否则大屏一片空白 |
| 数据回放兜底 | 准备一套录制好的仿真任务数据，实时链路出问题时切「回放模式」，照样能完整演示从下单到交接的全过程 |

## 附录 A 术语

本文特有：

| 术语 | 含义 |
|---|---|
| 十字准星 | 会面点的动态标记，随预测刷新移动 |
| 置信椭圆 | 预测不确定性的可视化表达，长短轴来自预测**标准差**：`a = 2·sigmaAlong`（沿航迹）、`b = 2·sigmaCross`（法向），旋转角取 `courseDeg`（见 `22` §4、`29` §3.3） |

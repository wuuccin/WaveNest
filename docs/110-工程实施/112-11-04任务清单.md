2026-11-04 是 1103 计划一收口后的补充验证日，用来复核计划一已合入代码的现场判据。1103 计划一的十六项代码已全部合入，本清单不重复实现这些代码。阶段三六项、阶段四三项与代码评审遗留问题共 48 条，按包分组由对应责任人领取，本清单只给张睿哲、罗才辉两个领取入口，不展开条目细节。

## 6 注意点

1. 阈值取配置或脚本参数，不硬编；键名与取值写进 PR 描述。
2. [007_pred_error_sample.sql](../../deploy/sql/007_pred_error_sample.sql) 已建表，复核人员只复核，不改结构；确需改表时，复核人员走组长批准。
3. 每条任务合并前 PR 的 base 是 `develop`；合并后由验收人复核 `git show --name-only` 无文档夹带。
4. 现场验证需要 MySQL、RabbitMQ、Redis、Mosquitto 四件套，起库步骤见[《运行环境说明》](../40-工程实施/41-运行环境说明.md)。
5. 构建只用 Wrapper，复跑命令固定为 `./gradlew build`。
6. 验证产物不进仓库，脚本、实验数据与截图都不入库，各责任人只把数字写进 PR 描述或台账。

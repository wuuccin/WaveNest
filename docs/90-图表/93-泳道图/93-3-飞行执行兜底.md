## 2 说明

1. **两条横切线**在这里合流落地：实时追踪＝`遥测→M1→M4→共享数据源`，M2 与 M3 按需取用；兜底＝`M4 检测上报 → M2 决策 → M3 改航或退避`。检测与决策分家，**不允许检测侧直接指挥飞控**（`21` §6、§7、`22` §5 硬约定）。其中**空域类检测**（临时禁飞、空域管制突现、多机航迹冲突）按会签裁决归 **M3 功能 15** 检测上报（`81` 附录「跨组裁决落地」B-4／B-5），其余兜底项仍归 M4。
2. **6a 与 6b 的分界**：变的是「船怎么走」就照旧纠偏（原机继续追）；变的是「这架机还行不行」才回上游重选。飞行中**不存在换机出口**，换机须待货物回收后重派（`21` §2 第 6b、§10、`33` §3.5）。
3. 末段四子阶段不建为独立任务状态，属 `末段交接中` 的内部过程；对接失败的三条出路是重试、悬停等待、放弃本次会面（`23` §4 约束 3、`32` §3.4）。

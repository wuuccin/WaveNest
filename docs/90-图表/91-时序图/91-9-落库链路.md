```mermaid
    M6 ->> M6: 归一：CGCS2000 / WGS84 与标准单位，落库与入缓存都生效
    M2 ->> M6: 写状态估计结果与常驻预测快照

    M3 ->> M6: 读空域与航道限制台账、应急迫降点台账、气象、阈值参数
    M6 -->> M3: 底图约束与阈值

    M2 ->> M6: 读机型能力、部署关系、巢内实例状态
    M6 -->> M2: 候选组合「机型 × 机巢 × 实例」＋ 被排除资源与原因
    M2 ->> M6: 占位登记：这架机、这个巢位、这个会面窗口、这个归巢时隙
    Note over M2,M6: 占位是原子操作，与时间窗校验同一事务 —— Redis 的活跃占位窗口 ＋ 库中的时隙台账
    M6 -->> M2: 占用登记成立，或冲突顺延次优
    M2 ->> M6: 第 5 步回写会面窗口与归巢时隙占位，并二次资源校验（与第 4 步占位同一事务）
    M2 ->> M6: 订单与任务状态、流转日志（任务期间同事务同值）
    M2 ->> M6: 第 8 步按实际电量与实时风况复核、向他巢申请应急迫停的准入判定
    M6 -->> M2: 落点：原驻巢 / 迫停巢 / 应急迫降点
    M2 ->> M6: 释放占位、更新无人机与订单状态

    M4 ->> M6: 实际航迹点、告警记录
    M5 ->> M6: 查订单、机队、告警与回放数据
    M6 -->> M5: 查询结果

    Note over M6: 实时最新四类进 Redis：船舶态势、无人机实时状态、气象实时、活跃占位窗口
    Note over M6: 历史与低频落 MySQL：ship_ais、flight_point、task_log 与各档案表
    Note over M2,M6: 更新状态时优先写 Redis、成功后异步落库；落库失败必须补偿或告警，不允许静默丢失（见 27 §4）
```

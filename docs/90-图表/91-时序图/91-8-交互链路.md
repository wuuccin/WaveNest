## 1 M5：下单、查询、推送、人工干预、回放

```mermaid
sequenceDiagram
    autonumber

    box rgb(245,245,245) 用户侧
    participant SR as 船员（船端 H5）
    participant DISP as 运营调度员（调度后台与大屏）
    participant OPS as 运维
    end

    participant M5 as M5 终端交互、可视化<br/>只渲染与收指令，不碰算法
    participant M2 as M2 调度引擎
    participant M4 as M4 飞行任务监控
    participant M6 as M6 数据库、缓存

    SR ->> M5: 下单：选船、物资类型、重量、紧急程度
    M5 ->> M2: POST /api/orders
    M2 -->> M5: 受理 / 延后触发调度 / 拒单
    M5 -->> SR: 状态回执与订单状态时间线（任务期间为任务状态的投影）

    DISP ->> M5: 打开订单列表与机队状态
    M5 ->> M6: GET /api/orders、/api/drones、/api/nests
    M6 -->> M5: 订单、机队、机巢占用与可用实例数
    M5 -->> DISP: 订单看板与无人机、机巢状态面板

    Note over M2,M4: 四类 WebSocket 推送（type 决定前端渲染分支）
    M2 ->> M5: ship_traj：船舶未来轨迹点列与不确定性 cov
    M4 ->> M5: drone_state：无人机位置、电量、飞行阶段
    M2 ->> M5: rendezvous：订单、会面点经纬度、是否锁定
    M4 ->> M5: alarm：级别、类型、目标、提示语
    M5 -->> SR: 飞行中实时卡片（到达倒计时、机位缩略图、会面点是否锁定）
    M5 -->> DISP: 大屏图层、统计面板、事件日志流

    DISP ->> M5: 人工干预：调整会面点 / 撤回未起飞的订单 / 取消订单 / 紧急叫停 / 一键冻结派单 / 转人工
    M5 ->> M2: POST /api/intervene
    M2 -->> M5: 干预结果（调整会面点后由 M2 重算航迹并重新校验可行性）
    Note over DISP,M2: 不提供「把货物直接改派给另一架机」，也不越过 M2 直接指挥 M3 或 M4

    DISP ->> M5: 拖动时间轴回放
    M5 ->> M6: GET /api/replay/{taskId}
    M6 -->> M5: 历史帧数据
    M5 -->> DISP: 倍速回放

    OPS ->> M5: 查看接入链路健康
    M5 ->> M5: 在线 / 断流 / 延迟（来源见 91-2）
```

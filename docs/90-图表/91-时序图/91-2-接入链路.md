## 1 M1 五路接入、解析、投递，以及上行指令的下发通道

```mermaid
sequenceDiagram
    autonumber

    box rgb(245,245,245) 外部
    participant EXT as 数据源<br/>AIS · 气象 · 水文 · 航道与空域公告
    participant UAV as 无人机与机巢链路
    end

    participant M1 as M1 数据采集<br/>连接器 → 解码器 → 发布器

    box rgb(232,245,233) 消费方
    participant M2 as M2 调度引擎
    participant M3 as M3 动态会面、路径规划
    participant M4 as M4 飞行任务监控
    participant M5 as M5 终端交互、可视化
    participant M6 as M6 数据库、缓存
    end

    Note over M1: 常驻层地基：不因订单启停，从开机起持续在线
    par 流式接入
        EXT ->> M1: AIS 船位报文（TCP、UDP，支持多基站）
        UAV ->> M1: 无人机遥测报文（MQTT，链路由本模块建立）
    and 定时轮询
        M1 ->> EXT: 拉取江面气象与水位流速
        EXT -->> M1: 原始报文
        M1 ->> EXT: 抓取航道管制与空域限制公告
        EXT -->> M1: 公告文本
    end

    M1 ->> M1: 解码（AIVDM 与 6-bit ASCII 载荷、遥测位段映射）与格式级校验
    M1 ->> M1: 封装统一信封 ParsedMessage（sourceId、type、ts、payload）
    M1 ->> M1: 接入链路健康：在线 / 断流 / 延迟

    M1 ->> M2: MQ data.ais 等：解析后的原始态势
    M1 ->> M3: MQ data.weather、data.hydro、data.notice：气象、水文与空域约束
    M1 ->> M4: MQ data.uav.telemetry：格式级已校验，M4 只做飞行语义级清洗
    M1 ->> M5: MQ data.ais、data.uav.telemetry：供实时图层
    M1 ->> M6: 历史数据落 ship_ais、weather、hydro、airspace_restriction；实时最新状态写 Redis

    Note over M1,UAV: 上行：指令由 M4 判定与编码，经本模块已建立的 MQTT 通道下发；本模块不判断该不该发
    M4 ->> M1: 上行飞行指令（已编码）
    M1 ->> UAV: 指令下发
```

## 2 说明

1. **遥测只接入一次**：M4 不直连 MQTT，其校验职责上移为飞行语义级（野值剔除、丢包外推）。
2. M6 不作为 MQ 消费方：落库与入缓存由 `M1 → M6` 的调用完成（见 `91-9`）。
3. M1 不做状态估计（归 M2）、不做坐标与单位归一（归 M6）、不建业务表。

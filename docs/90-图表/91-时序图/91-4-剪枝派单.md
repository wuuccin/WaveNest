## 1 第 3 步：候选组合展开与两关剪枝

```mermaid
sequenceDiagram
    autonumber

    box rgb(227,242,253) 调度层
    participant DP as 调度引擎 M2<br/>展开 · 两关剪枝
    end

    box rgb(232,245,233) 预测层
    participant TP as 轨迹预测<br/>本单船舶预测轨迹
    end

    box rgb(243,229,245) 存储层
    participant DB as 存储与台账 M6<br/>档案与实例状态
    end

    participant RS as 会面求解 M3<br/>逐组合解相遇点

    DP ->> TP: 取本单船舶预测轨迹（第 2 步产物）
    TP -->> DP: 轨迹 ＋ 进入各巢时刻
    DP ->> DB: 查机型能力、部署关系、巢内实例状态
    DB -->> DP: 候选组合「机型 × 机巢 × 实例」＋ 被排除资源与原因
    Note over DP: 第 3 步 · 候选组合展开：货物关 → 机型关 → 机巢 × 巢内当前可用实例
    Note over DP: 静态先剪、动态后剪；实例是否空闲在展开时就过掉，不占剪枝关；展开全程不看船
    loop 逐候选组合过两关（会面点是组合级产物，每个组合各算各的）
        DP ->> DP: ① 追得上吗？用相对运动关系求本组合自己的会面点
        DP ->> RS: 求本组合的会面点（机型速度 · 机巢起点 · 风况修正 · 船舶预测轨迹）
        alt 无实数解
            RS -->> DP: 追不上 —— 连返程电量都不必再算，该组合直接淘汰
        else 有解
            RS -->> DP: 会面点 ＋ 会面时间窗 ＋ 理论飞行时长
        end
        DP ->> DP: ② 回得来吗？归巢目标默认原驻巢，验电量覆盖「去程 ＋ 交接 ＋ 返程 ＋ 余量」整环
        alt 两关任一不过
            DP ->> DP: 淘汰该组合（原巢回不去即淘汰，派单阶段不安排改投）
        else 两关全过
            DP ->> DP: 该组合自带 会面点 · 归巢目标 · 待回填的起飞时刻
        end
    end
    break 可行组合集为空
        DP ->> DP: 出口：拒单 / 延后等资源 / 转人工
    end
```

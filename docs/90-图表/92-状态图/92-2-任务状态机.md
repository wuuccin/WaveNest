## 1 一次飞行一个状态：5 个正常态 ＋ 3 个异常态

```mermaid
stateDiagram-v2
    direction LR
    accTitle: 任务状态机
    accDescr: 任务从已派发起算，经去程中、末段交接中、返航中到已完成，异常分支有迫停中、迫降待回收、异常终止三个状态。

    state "已派发 · 方案已下发 M4" as Dispatched
    state "去程中 · 第 6 步" as Outbound
    state "末段交接中 · 第 7 步" as Handover
    state "返航中 · 第 8 步" as Returning
    state "已完成 · 落巢确认" as Done
    state "迫停中 · 已获准临时停靠他巢" as Parked
    state "迫降待回收 · 落在应急迫降点" as Grounded
    state "异常终止 · 无人机灭失" as Terminated

    [*] --> Dispatched : 第 5 步精算与起飞时刻回填完成，任务方案下发 M4

    %% ===== 正常路径 =====
    Dispatched --> Outbound : M4 确认起飞
    Outbound --> Handover : M3 判定进入会面点邻域
    Handover --> Returning : 交接完成确认
    Returning --> Done : 落巢确认（原驻巢或他巢迫停均算任务闭环，落点另记）

    %% ===== 异常分支 =====
    Returning --> Parked : 返航复核判定回不了原驻巢，向近处机巢申请应急迫停并获准入
    Parked --> Done : 落他巢，落点记为迫停巢
    Returning --> Grounded : 无可借机位，转入应急迫降点
    Grounded --> [*] : 转人工回收（对应订单进入失败）
    Outbound --> Terminated : 无人机灭失判定成立
    Handover --> Terminated : 无人机灭失判定成立
    Returning --> Terminated : 无人机灭失判定成立
    Done --> [*]
    Terminated --> [*]

    note right of Outbound
        6b 意图变更、风速突变、临时禁飞都不新增任务状态，
        只触发调度侧重跑，状态仍停在去程中。
    end note

    note right of Handover
        末段内部的四子阶段（接近、匹配、交接、脱离）不建为独立状态，
        属于末段交接中的内部过程。
    end note

    note left of Dispatched
        任务状态只由已派发起算，不含待受理一类订单阶段。
    end note
```

## 2 说明

1. `已派发` 到 `返航中` 四态与订单状态**同名同值**，任务侧变更在同一事务内回写订单（`23` §5）。
2. `迫停中`、`迫降待回收` 是任务侧独有，不在订单侧展开，由落点字段与订单终止态表达。
3. 状态写入方：除 `迫停中`／`迫降待回收`（M4 上报、M2 决策）与失联灭失类（M4 判定上报）外，任务状态推进均由 M4 在事实发生时写入（`23` §8）。

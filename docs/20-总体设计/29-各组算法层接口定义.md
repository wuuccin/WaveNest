## 1 本文定位与边界

### 1.1 本文是什么

本文是**从 `80`–`86` 七份算法方案直接抽取汇总**的 A–G 各组算法层接口清单，逐组给出「我产出什么对象（含字段）」与「我消费什么（从哪组接、什么粒度）」。

### 1.2 权威性层级（先说清，避免误解）

| 层级         | 内容         | 权威处                            |
| ---------- | ---------- | ------------------------------ |
| 对象名、字段名、含义 | **各组自定**   | 各组算法方案 `80`–`86`（本文照抄，不改名、不新造） |
| 汇总与索引      | 本文         | 本文 §2、§4                       |
| 最终锁死       | 回填 `22` §2 | `22` v1.0（待各组会签后由组长记录）         |

本文**不发明任何字段**。凡字段缺失处标「**待本组补**」，指向 `分发/前置-待裁决/` 本组《待裁决前置事项》的对应条目。

### 1.3 边界（本文不含什么）

- **不含模块层接口**。MQ 主题名、REST 路径、WebSocket 帧字段属模块层（M1–M6），`22` §7 已注明待 `30`／`35`／`36` 后再收，本文不涉及。
- **不含具体取值**。阈值、权重、系数只列名目与含义，取值一律读 `sys_param`，不写死。
- **不含数值演算**。只给判断依据与结构，不展开公式推导与代入。

### 1.4 体例说明

- 字段表按 A 组 `80` §2.3 的体例（字段／类型／单位／说明）给出；各组原文档已给字段表的，照抄原表。
- 「产出」表中的**消费方**列给出下游组（或模块）；「消费」表给出来源组与粒度。
- 标记含义：`【待本组补】`＝原方案只有内容描述、无字段表，需该组补齐（对应分发件 C-04）。
- **状态列口径**：已定义＝本组字段表已入**项目库**且可回源；【待补】＝该组方案尚无字段表，或实物未进项目库、或会签未完成。**实物已交付但未进项目库或未会签的，一律仍标【待补】**（防止本文与各组方案两份权威文档互相矛盾）。
- **关闭标记口径（2026-10-12 新增）**：**「已确认」≠「已关闭」**。「已确认」＝双方对内容达成一致、但未走关闭标记（本文 §5 的 C-02、C-11 属此类）；「已关闭」＝已标关闭（C-01、C-03、C-04、C-07～C-10、G-01、G-03、F-battery）。**引用本文状态时不得把「已确认」表述为「已关闭」**；同理「单边已定」（E 组侧已定、待对方回执：C-05、C-12）与「主责侧已定稿、余对方核对一句」（C-06）均**不算关闭**。
- **责任组口径**：本表「责任组」列未分主责／协同（建议 A-05，已登记）；已明确的条目就地标注「主责＝X」，其余待各组确认后统一补列。组长不代定他组主责。

## 3 各组接口定义


### 3.1 A 组（态势与预测，责任人 卢肄文，方案 `80`）

对应官方清单：功能 1（订单接入与基本校验）、功能 2（船舶状态估计与轨迹预测管理）。

#### 3.1.1 我产出

**（1）`PredictionSnapshot`（预测快照）** — 定义处 `80` §2.3

| 字段                  | 类型     | 单位       | 说明                                                                                                         |
| ------------------- | ------ | -------- | ---------------------------------------------------------------------------------------------------------- |
| `version`           | string | —        | 快照版本号                                                                                                      |
| `trigger`           | enum   | —        | 触发方式：`RESIDENT`（常驻滚动）／`ON_DEMAND`（接单按需）／`REESTIMATE`（纠偏重估）。跨组裁决 A-7：快照带「触发方式／生成时刻／有效期」三元组，下游按场景显式选择，不得隐式取用 |
| `shipMMSI`          | string | —        | 目标船标识                                                                                                      |

| `calibrationFactor` | double | —        | 标定因子 `c`，由 NEES 一致性检验标定；下游须判 `NIS₂ / c` 或改用 `k·σ`（跨组裁决 A-1、A-6）                                            |

| `premise`           | object | —        | `{status: VALID／INVALID／NOT_APPLICABLE, reason, since}`                                                    |
| `branchId`          | string | —        | 分汊锁定分支；未锁定时为 `null`                                                                                        |
| `branchProb`        | double | 0–1      | 最大分支概率，供风险项使用                                                                                              |
| `points`            | array  | —        | 时间升序、等步长，见下表                                                                                               |
| `enterTimes`        | map    | epoch ms | `nestId → 预计进入该巢服务范围的时刻`                                                                                   |
| `stateAt0`          | object | —        | `{s, v_s, e, deDt, covSS, covEE, trackDeg, rotDegPerMin, navPhase, dirRef}`，供纠偏与下游特征复用；`v_s` 带符号（上行为负）     |
| `deviation`         | object | —        | `{xteM, xteSigned, dCogDeg, rho, basisVersion, samples}`：相对本快照的带符号横向偏差、滑窗平均航向差、速度缺口比、基准版本号与样本数             |

| 字段           | 类型     | 单位       | 说明               |
| ------------ | ------ | -------- | ---------------- |
| `t`          | long   | epoch ms | 该点时刻             |
| `lon`、`lat`  | double | 十进制度     | 基准坐标系            |
| `s`、`e`      | double | m        | 沿航道里程、横向偏移（左正右负） |
| `v`          | double | m/s      | 沿航道速度            |
| `cog`        | double | 度        | 该段航迹方位           |
| `sigmaAlong` | double | m        | 纵向不确定度           |
| `sigmaCross` | double | m        | 横向不确定度           |

**消费方**：B（12 会面求解）、C（功能3 粗筛、功能4）、D（§2.5 上游输入）、E（功能17 船侧预测）。

> **不确定度形式的对外约定（`80` §2.6）**：对外交付的是**标准差标量对 ＋ 主轴方位**（`σ_along`、`σ_cross`、`courseDeg`），不是经纬度 2×2 协方差矩阵；需矩阵时按 `Cov = R(ψ)·diag(σ_along², σ_cross²)·R(ψ)ᵀ`（`ψ = courseDeg`）重建。该协方差形式与标定因子 `c` 一并写入 `22`（A-6，对应分发件 C-01）。

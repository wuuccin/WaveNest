## 2 各人具体

### 2.1 吴可欣：连跑三次与抓帧

- **做法**：每遍走完下单、派发、去程、末段交接、返航、完成六个环节。每遍之间调用 `POST /sim/ship/reset` 复位，并清理上一单的订单、轨迹与日志。第二遍飞行途中重启后端。
- **抓帧**：抓 WebSocket 的 `ship_traj` 帧存成文件，每帧记 `t0`、`validitySec`、`premise`，以及 `points[]` 每点的 `t`、`lon`、`lat`，另记 `sigmaAlong`、`sigmaCross`，半轴取 2σ。
- **判据**：三遍全部自动走完且无需人工推进；重启后 WebSocket 自动重连、`GET /api/replay/{droneId}` 补齐帧、订单续到完成；写明每遍起止时间戳与重启时刻。

## 3 注意点

- **环境**：旧数据卷里机巢是武汉坐标、004 空域未灌，会导致候选全淘汰。各人自行执行 `cd deploy && docker compose down -v && docker compose up -d` 重灌。
- **`deploy/sql` 只在空卷执行一次**：卷已存在时 `up -d` 不重跑脚本。
- **链路异常（`LINK_ERROR`）当前无检测器**：五类里今天只覆盖四类。是否补检测器或从对外口径去掉，由组长今天定，不边跑边加。
- **压岸只能目视**：代码里没有岸线与江心洲数据，不硬编江面半宽数值。
- **清理已合入 develop 的个人分支**：共 12 个，卢肄文 3 个、彭紫情 1 个、罗才辉 1 个、张睿哲 1 个、宋冰鑫 2 个、吴可欣 4 个，用完即清。
- **拉代码用完整路径的 `git.exe`**：不要用 PATH 里的便携版，便携版可能走坏代理返回 502。构建只用 Wrapper 的 `./gradlew`，不跑本机 gradle。

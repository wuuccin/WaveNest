## 0. 结论

建议采用一条有依赖关系的技术路线：
```text
原始飞行状态
    |
    v
20 数据校验过滤
    |  输出可用状态、异常标记、短时补全状态
    v
21 当前位置投影到规划航线
    |  输出偏航距离、投影点、当前航段、航段内位置
    +------------------+
    v                  v
22 飞行进度定位        23 剩余航程估算
```
推荐的最小可行方案：

数据校验过滤：范围规则 + 时间连续性 + 运动学一致性 + MAD 鲁棒异常判别。

短时丢包：离线验证使用两端点之间的球面插值；实时运行使用速度/航向的短时航迹外推；超过允许间隔不补。

偏航距离：将当前位置与每个规划航段计算点到球面线段的最短距离，取最小值；同时返回最近航段和投影点。

飞行进度：复用 21 的最近航段和航段内投影距离，避免重复计算。

剩余航程：正常沿计划飞行时，从投影点沿规划航线计算剩余距离；返航或偏离航线时不沿用原航线，由 E 组功能 10 粗估、B 组功能 16 精算。

## 1. 资料来源与用途

### 1.1 飞行状态字段与测试数据

- [OpenSky Network REST API 官方文档](https://openskynetwork.github.io/opensky-api/rest.html)
- 可作为输入字段定义的参考。
- 状态向量包含时间、WGS-84 经纬度、气压高度、地速、真航迹、垂直速度等字段。

- [OpenSky Network 官方 API 总览](https://openskynetwork.github.io/opensky-api/)
- 可用于获取公开的真实飞行轨迹样例。
- 项目数据若不能直接使用真实数据，可只借鉴字段结构，使用合成轨迹做验证。

### 1.2 异常检测与鲁棒统计

- [NIST：Detection of Outliers](https://itl.nist.gov/div898/handbook/eda/section3/eda35h.htm)
- 说明异常点识别、鲁棒方法和 modified Z-score。
- 推荐用中位数和 MAD 替代均值和标准差，降低野值对阈值估计的影响。
- [NIST：Median Absolute Deviation](https://itl.nist.gov/div898/software/dataplot/refman2/auxillar/mad.htm)
- 给出 MAD = median(|x - median(x)|) 的定义。
- 可用于速度残差、位置预测残差、垂直速度残差等特征。

### 1.3 地理距离与航段计算

- [Karney, Algorithms for geodesics](https://arxiv.org/abs/1109.4448)
- 给出椭球面测地线正解、反解等高精度算法。
- [GeographicLib 官方说明](https://geographiclib.sourceforge.io/geod.html)
- 提供 C/C++、Python、Java、JavaScript 等实现。
- 若后续精度要求提升，可将球面距离替换为 WGS-84 椭球测地线距离。
- [GeographicLib Python API](https://geographiclib.sourceforge.io/html/python/code.html)
- Inverse 可求两点距离和方位角。
- InverseLine/Position 可在一条测地线上按距离取点。

### 1.4 资料使用边界

- 公开资料用于定义字段、距离计算和鲁棒统计方法，不替代项目内部状态词和接口约定。
- 本组不负责模块一的格式级解析，也不负责模块二的船舶状态估计。
- 真实项目是否使用 WGS-84 椭球、球面半径、航路类型和单位，最终以项目统一口径为准。

### 3.3 算法设计

#### 3.3.1 总体策略

采用“硬规则先筛、运动学再判、鲁棒统计辅助、分级处理输出”的策略。
```text
原始点
  -> 字段存在性与取值范围检查
  -> 时间顺序与重复点检查
  -> 相邻点运动学一致性检查
  -> 预测残差的 MAD 鲁棒判别
  -> 正常 / 野值 / 短时丢包 / 长时缺失
  -> 输出状态与质量标记
```
#### 3.3.2 基础校验

对每个点检查：

timestamp 是否存在，是否与上一点保持时间顺序。

经纬度是否在合法地理范围内。

高度、地速、垂直速度是否满足项目定义的物理范围。

航向是否可归一化到项目约定角度范围。

是否出现完全重复点、重复时间或关键字段全部为空。

这些属于语义级校验，不能替代模块一的格式级校验。

#### 3.3.3 运动学一致性

相邻点之间计算：

- delta_t：时间间隔。
- distance_obs：相邻经纬度的球面距离。
- speed_implied = distance_obs / delta_t：由位置反推的平均地速。
- speed_residual = |speed_implied - ground_speed|：位置与地速残差。
- acceleration_est：相邻地速变化率。
- turn_rate_est：航向变化率，需先处理 0/360 度环绕。
- vertical_speed_implied：由高度差和时间间隔反推的垂直速度。
- vertical_rate_residual：反推垂直速度与上报垂直速度的差值。

判定原则：

- 单项超过项目边界时，标记对应异常原因。
- 多项同时异常时，提高异常等级。
- 不能因为一个字段为空就直接丢弃整条状态；应按字段能力降级。

#### 3.3.4 野值判别

对以下残差序列使用滑动窗口 MAD：

- 位置预测残差。
- 速度残差。
- 垂直速度残差。
- 必要时的航向变化残差。

位置预测可采用上一有效状态的短时匀速模型：
```text
predicted_position =
    从上一有效位置沿上一有效航向前进 ground_speed * delta_t
position_residual =
    distance(observed_position, predicted_position)
```
改进判据：
```text
modified_score =
    scale_factor * (residual - window_median) / window_MAD
```
当使用正态参考的 modified Z-score 时，scale_factor 取 0.6745；MAD 为零或窗口样本不足时，退回硬规则或相邻点一致性判定，不能直接做除零计算。

#### 3.3.5 短时丢包处理

分为离线回放和实时流式两种情况：

离线回放

- 已知丢包区间两端的有效点。
- 水平位置沿两端点之间的球面航线插值。
- 高度采用时间线性插值。
- 地速可采用线性插值或邻域稳健值。
- 航向采用圆周角插值，不能直接普通线性插值跨越 0/360 度。

实时流式

- 只有最近一个有效点时，按最近有效地速、航向做短时外推。
- 每次外推都累计“已连续外推时长”。
- 超过允许的最大外推时长后停止补点，输出缺失状态。
- 外推结果必须标记 imputed 或项目对应状态词，不能伪装成原始观测。

#### 3.3.6 分级处理

建议输出以下处理结果，具体状态词沿用项目既定口径：

| 情况 | 处理 | 是否参与后续计算 |
| --- | --- | --- |
| 正常点 | 原样通过 | 参与 |
| 可疑但未确认野值 | 保留原值并标记 | 按项目策略 |
| 确认野值 | 用邻域/预测值替换清洗值，保留原始值 | 使用清洗值 |
| 短时丢包 | 插值或短时外推 | 使用补全值并带标记 |
| 长时间缺失 | 不补，输出缺失 | 不参与距离和进度计算 |

### 3.5 验证方式

数据

真实轨迹回放：使用项目历史数据或公开飞行轨迹字段结构。

合成正常轨迹：设置不同直线、转弯、爬升、下降场景。

注入异常数据：

- 经纬度突跳。
- 高度突跳。
- 速度异常。
- 时间乱序。
- 单点野值。
- 短时连续丢包。
- 长时连续丢包。

指标

- 野值检测 Precision、Recall、F1。
- 清洗后位置 MAE、P95 误差。
- 补全点位置误差和高度误差。
- 清洗后运动学违规率。
- 实时外推延迟和停止补全是否符合边界。
- 原始点、清洗点、补全点是否可追溯。

重点场景

- 直线匀速。
- 匀速转弯。
- 爬升或下降。
- 航向跨越 0/360 度。
- 连续两端存在有效点的短时缺口。
- 只知道缺口前状态的实时外推。

### 3.6 已确定口径

- 状态词采用 raw_valid、cleaned_valid、imputed_valid、missing；anomaly_flags 记录异常原因，state_quality 表示当前结果的可用等级。
- 当前算法使用 ground_speed 和 true track；true track 统一定义为以正北为 0、顺时针增加的航迹角。空速不参与本组 20～23 的水平几何计算。
- 清洗值可驱动 21～23；补全点可驱动几何距离和投影计算，但必须携带 imputed 标志，不能单独触发告警或航点到达结论。
- 阈值不写死为跨项目通用常数：离线插值缺口不超过 3 个正常采样间隔，实时外推不超过 2 个正常采样间隔；具体秒数由历史轨迹回放标定，超过上限立即停止补全。
- 确认野值采用“保留原始值、标记异常、生成清洗值”的策略，不直接删除原始记录。
- 高度必须使用项目接口明确的单一参考系（气压高度或几何高度），禁止混用；未声明参考系时不进行垂直速度一致性判定。
- 实时模式不等待下一点；只有离线回放允许使用缺口两端的有效点做插值。

输入粒度

- 规划航线：一个有序航点序列；相邻航点构成一个航段。

deviation_result = {

    flight_id,

    route_id,

    route_version,

    input_timestamp,

    deviation_distance,

    nearest_segment_index,

    nearest_waypoint_before,

    projection_point,

    along_track_distance,

    cross_track_side,

- 只计算几何偏航距离并输出投影点、最近航段和沿航段距离；本功能只产量、不判级、不产告警，告警分级由G组功能24负责。

}

其中 deviation_distance 是点到规划航线的最短距离，projection_point 是航段内部投影点或最近端点。

- 只计算几何偏航距离并输出投影点、最近航段和沿航段距离；本功能只产量，不判定预警/严重等级，告警分级由 G 组功能 25 负责。
- 不负责航线重规划。
- 不负责高度层偏差；除非项目明确要求，否则本功能只处理水平面经纬度距离。
- 规划航段默认按球面大圆弧处理；若项目使用恒向线或三维航段，需要另行确认。

### 4.3 算法设计

#### 4.3.1 选型

采用“点到每个球面线段的最短距离，取全局最小值”。

选择原因：

- 直接符合“最短垂直距离”的定义。
- 能同时返回最近航段、投影点和航段内位置，供 22 和 23 复用。
- 航段数量通常有限，复杂度为 O(number_of_segments)，实现和验证简单。
- 后续可把球面距离替换成 GeographicLib 的 WGS-84 椭球距离，不改变上层接口。

#### 4.3.2 球面距离

令纬度、经度转为弧度，球面半径为 EARTH_RADIUS。

两点间角距离可用 Haversine：
```text
a = sin²((lat2 - lat1) / 2)
  + cos(lat1) * cos(lat2) * sin²((lon2 - lon1) / 2)

central_angle = 2 * asin(sqrt(a))
distance = EARTH_RADIUS * central_angle
```
#### 4.3.3 点到球面线段

对当前位置 P 和航段端点 A → B：

计算 A → P 和 A → B 的球面角距离。

计算从 A 出发到 P、到 B 的初始方位角。

计算球面大圆上的横向角距离：
```text
cross_track_angle =
    asin(sin(angle_AP) * sin(bearing_AP - bearing_AB))
```
计算沿航段方向的带符号距离：
```text
along_track_angle =
    atan2(
        sin(angle_AP) * cos(bearing_AP - bearing_AB),
        cos(angle_AP)
    )
```
进行线段边界判断：

- 若 along_track_angle < 0，最近点是 A。
- 若 along_track_angle > angle_AB，最近点是 B。
- 否则，最近点在航段内部，垂直距离为：
```text
deviation_distance =
    EARTH_RADIUS * abs(cross_track_angle)
```
对全部航段取最小距离。

注意：

- 角度运算前要统一到弧度。
- 经度差要处理跨越 ±180 度的情况。
- asin 入参需要进行数值截断，防止浮点误差略超 [-1, 1]。
- 若航点重复或航段长度接近零，跳过该航段或按端点处理。

#### 4.3.4 最近航段的连续性

当多个航段距离非常接近时，单纯取最小值可能在相邻航段之间抖动。可增加：

- 上一时刻最近航段索引。
- 航段切换迟滞参数。
- 沿航线进度的单调性约束。
- 仅在新航段优势超过切换界限时切换。

这些策略用于稳定结果，不改变几何距离定义。

### 4.4 参数与阈值清单

| 参数名 | 含义 |
| --- | --- |
| EARTH_RADIUS | 球面距离计算使用的地球半径 |
| ANGLE_EPSILON | 角度比较的数值容差 |
| DEGENERATE_SEGMENT_LIMIT | 近零长度航段判定界限 |
| SEGMENT_SWITCH_MARGIN | 最近航段切换迟滞量 |
| MAX_ROUTE_SEGMENT_CANDIDATES | 可选的候选航段数量上限 |
| LONGITUDE_WRAP_POLICY | 经度跨越 ±180 度时的归一化规则 |

### 4.5 验证方式

基础几何用例

- 点在线段上：偏航距离接近零。
- 点在线段左侧/右侧：距离方向正确。
- 最近点为航段起点。
- 最近点为航段终点。
- 点位于两个航段连接处。
- 航线跨越经度 ±180 度。
- 极短航段和重复航点。

指标

- 与人工构造真值的绝对误差。
- 与 GeographicLib/WGS-84 结果的差异。
- 最近航段识别准确率。
- 连续轨迹上的距离抖动次数。
- 单条轨迹全量计算耗时。

建议验收图

- 规划航线、当前位置、投影点三者的地图示意图。
- 偏航距离随时间变化曲线。
- 球面算法与椭球算法的误差对比曲线。

### 4.6 已确定口径

- 球面计算的默认 EARTH_RADIUS 取 6371008.8 米；项目若统一指定其他半径，以项目接口配置为准。
- 规划航段默认按球面大圆弧处理；若项目要求椭球精度，使用 GeographicLib 的 WGS-84 实现替换距离内核；恒向线不是默认表示。
- deviation_distance 始终输出非负距离；方向信息通过 cross_track_side 单独输出，不把正负号混入距离字段。
- 功能 21 只处理水平经纬度几何量，高度层偏差不并入 deviation_distance；如需三维偏差，另设接口字段和验收指标。
- 航线保留上游给出的顺序；重复航点对应的近零航段跳过或按端点处理；若存在自交，不擅自改线，仍按各航段最小距离计算并将 route_quality 标为低质量。

## 5. 功能 22：飞行进度定位

### 5.1 研究范围

- 序号：22
- 功能名：飞行进度定位
- 所属模块：模块四 飞行任务监控
- 回答的问题：当前飞行器位于哪个航点附近、哪个规划航段，以及在该航段上前进了多远？

### 5.2 输入与输出

输入来源

- 20 输出的当前有效位置。
- 21 输出的最近航段、投影点和沿航段距离。
- 规划航线的有序航点数组。

输入粒度

- 当前状态：单点。
- 规划航线：有序航点序列。
- 可选历史状态：上一时刻航段和进度，用于稳定切换。

输出

### progress_result = {

### flight_id,

### route_id,

### route_version,

### input_timestamp,

### current_waypoint_index,

### current_segment_index,

### segment_progress_distance,

### route_progress_distance,

### route_progress_ratio,

### projection_point,

### progress_quality

### }

### 5.3 算法设计

功能 22 保留独立接口章节，但算法依附 21，不再单独重新计算点到航线距离；参数沿用 21 的投影与航段切换参数。

从 21 得到最近航段 segment_i = (W_i, W_{i+1})。

得到当前位置在该航段上的投影点 Q。

计算：
```text
segment_progress_distance = distance(W_i, Q)
route_progress_distance =
    cumulative_route_distance_before_segment_i
    + segment_progress_distance
```
用航段边界、航点到达判据判断当前航点：

- 距离 W_i 更近且尚未越过航段起点时，认为位于航点 W_i 附近。
- 接近或越过 W_{i+1} 时，切换到下一个航段。
- 航点到达判据由项目阈值控制，不能直接把“最近点”当成“已到达”。

计算进度比例：
```text
route_progress_ratio =
    route_progress_distance / total_route_distance
```
应对抖动：

- 保存上一时刻航段和进度。
- 设置航段切换迟滞。
- 对进度增加非回退约束，但在返航、重规划或任务重置时清空历史约束。

### 5.4 参数与阈值清单

| 参数名 | 含义 |
| --- | --- |
| WAYPOINT_REACHED_DISTANCE | 航点到达判定距离 |
| SEGMENT_SWITCH_MARGIN | 航段切换迟滞量 |
| PROGRESS_BACKTRACK_TOLERANCE | 允许的进度小幅回退量 |
| PROGRESS_RESET_CONDITION | 重规划、返航等导致进度重新计算的条件 |
| MIN_SEGMENT_LENGTH | 可参与进度计算的最小航段长度 |
| PROGRESS_QUALITY_POLICY | 原始、清洗、补全状态参与进度输出的策略 |

### 5.5 验证方式

- 当前位置分别位于航段起点、中点、终点。
- 轨迹经过航点但有定位噪声。
- 当前位置在相邻航段交界处来回抖动。
- 轨迹存在短时丢包和补全点。
- 航线中存在短航段、重复航点。
- 返航或规划航线更新后重新定位。

指标：

- 当前航段识别准确率。
- 航点到达判定准确率。
- 进度距离 MAE。
- 进度比例是否单调。
- 航段切换抖动次数。
- 重规划后恢复时间。

### 5.6 已确定口径

- current_waypoint_index 定义为当前航段的下一目标航点；进入 WAYPOINT_REACHED_DISTANCE 后标记该航点 reached，并切换到下一航段。
- 航点状态采用 approaching、reached、passed、off_route；最终展示名称可映射为项目统一状态词，但语义保持不变。
- 返航或偏离航线后，功能 22 停止沿原计划航线推进，输出 return_mode 或 off_route；返航路线由 E 组功能 10 与 B 组功能 16 处理，F 组不自行选路。
- 航线更新仅在 route_id 和 route_version 连续且坐标系一致时保留历史进度；否则清空上一航段和进度约束，重新定位。
- 补全点可以更新几何进度，但不能单独触发航点到达或航段切换；到达结论至少需要清洗有效点确认。

## 6. 功能 23：剩余航程估算

### 6.1 研究范围

功能定位：消费方。正常沿计划飞行时，消费上游归巢决策（E组功能10）给出的目标落点及所在航段信息，计算沿规划路径的剩余距离；返航或偏离航线时转由 E 组功能 10 粗估、B 组功能 16 精算。

- 序号：23
- 功能名：剩余航程估算
- 所属模块：模块四 飞行任务监控
- 回答的问题：正常沿计划飞行时，从当前沿规划路径的位置到目标落点还剩多远？返航或偏离航线场景不沿用本功能的原规划航线距离。

### 6.2 输入与输出

输入来源

- 20 输出的当前有效位置。
- 21/22 输出的投影点、当前航段和路线进度。
- 规划航线。
- 上游归巢决策（E组功能10）提供的归巢落点。

输入粒度

- 当前投影状态：单点。
- 规划航线：有序航点数组。
- 归巢落点：E组功能10提供落点类型、标识、坐标和 decision_version；类型为 MACHINE_SLOT（机位标识）或 POINT（野外点标识）。F组不推断或改写落点语义。

输出

remaining_route_result = {

    flight_id,

    route_id,

    route_version,

    remaining_distance,

    current_segment_index,

    destination_point,       // E组提供；标识原样传递，坐标用于几何计算

    route_end_distance,

    decision_version,

    calculation_quality

}

输出消费方：供 E 组功能 10（能量可行性判定）与 G 组功能 25（低电量预警）消费；输出必须携带 route_version、decision_version 和 calculation_quality。

边界

- 正常沿计划飞行时估算沿规划路径的剩余距离，不是当前位置到落点的直线距离；返航或偏离航线不使用本功能的原航线结果。
- 不估算剩余时间、油耗、电量或到达概率。
- 不负责决定归巢落点。
- 正常沿计划飞行但没有可靠规划路径时，输出 not_computable/low_quality；返航或偏离航线时转交 E 组功能 10 粗估、B 组功能 16 精算，不得用直线距离冒充本功能航程。

### 6.3 算法设计

仅在正常沿计划飞行模式下，将上游归巢决策（E组功能10）给出的目标落点视为规划路径终点的附加点。若当前投影点位于航段 i：
```text
remaining_distance =
    distance(projection_point, W_{i+1})
    + sum(distance(W_j, W_{j+1}))
      for j = i+1 ... n-1
    + distance(W_n, landing_point)
```
若当前投影点已经位于目标落点所在的附加航段，则只累加投影点到落点的剩余距离；返航或偏离航线模式不进入此分支。

实现步骤：

功能 23 保留独立接口章节，复用 21 的 projection_point 和最近航段；算法说明、参数和验证均以 21 的结果为前置，不重复实现投影。

预先计算规划航线的累计距离数组，避免每次重复累加。

将归巢落点作为末端航点，计算末端连接距离。

处理当前位置超出航线起点/终点的情况：

- 在起点前：按项目策略从起点开始或输出低质量。
- 超过终点或明显偏离规划航线：输出 off_route/transfer_to_return_estimator，不自行使用当前位置到落点的直线末段。

输出距离和计算质量，不输出没有依据的 ETA。

### 6.4 参数与阈值清单

| 参数名 | 含义 |
| --- | --- |
| LANDING_POINT_VALIDITY_RULE | 归巢落点有效性判定 |
| ROUTE_END_CONNECTION_POLICY | 末端航点到归巢落点的连接方式 |
| OFF_ROUTE_REMAINING_POLICY | 当前位置明显离开航线时的处理方式 |
| PROJECTION_VALIDITY_LIMIT | 投影结果可参与剩余航程计算的界限 |
| DISTANCE_RECALCULATION_POLICY | 航线或落点变化时的累计距离更新规则 |
| REMAINING_DISTANCE_PRECISION | 输出距离精度 |

### 6.5 验证方式

- 当前点在首个航段、中间航段和末端航段。
- 归巢落点恰好等于最后航点。
- 归巢落点位于最后航点之后。
- 当前点偏离航线但仍能投影到航段。
- 归巢落点缺失、越界或发生变化。
- 规划航线重新下发。

指标：

- 与手工累计距离的绝对误差。
- 与 GeographicLib 参考结果的误差。
- 归巢落点变化后的更新正确性。
- 航线前进过程中剩余距离是否总体下降。
- 对明显离线点是否正确输出低质量/不可计算状态。

### 6.6 已确定口径

- “剩余航程”沿规划航线只适用于正常沿计划飞行；返航、迫停他巢和迫降野外由 E 组功能 10 粗估、B 组功能 16 精算。
- 上游归巢决策可以实时更新；每次更新必须带 decision_version，23 重新计算并丢弃旧版本结果。
- 超出规划航线时输出 off_route，并把估算责任转交 E 组功能 10 与 B 组功能 16，不自行选择落点或路线。
- 23 默认只计算水平经纬度距离；三维空间距离不纳入本接口，除非项目另行定义三维版本。
- 落点及所在航段由上游归巢决策随 decision_version 一并给出；缺失或版本不一致时输出 not_computable。

### 8.1 已落地的跨组裁决

- F-2：F组只产偏航距离、投影点、最近航段和相关几何量；G组功能24负责偏航等级判定，F组不输出告警等级。
- F-3：21 的输入必须是项目基准坐标系；M6 在落库或入缓存时完成归一，并交付坐标系说明。
- F-4：23 输出供 E 组功能 10 与 G 组功能 25 消费，并携带 route_version、decision_version 和 calculation_quality。
- F-5：开头重复标题已删除，正文只保留一次模块四 20 至 23 号功能说明。
- F-7：确认野值标记并替换；补全点可驱动几何量，但必须携带 imputed 标志，由下游决定是否采信。
- F-8：归巢落点及所在航段由 E 组功能 10 随归巢决策给出，23 为消费方。
- 项目红线：遵守“起飞后不换机、不改派”“返航目标唯一为原巢”“迫停与迫降分离”“原巢→迫停他巢→迫降野外逐级校验”。F 组不越权选择返航落点。
- 说明文件中的四项归属变更已核对：气象超限告警归 G，临时禁飞检测归 B 组功能 15，派单闸门归 D，纠偏阈值标定归 E；这些事项不属于 F 组功能正文，F 组不越权展开。

### 8.2 本组接口统一口径

- F-6：功能22、23保留独立接口定义并复用功能21的投影结果，不重复实现航线投影。
- F-9：正常沿计划飞行且路线不可用时输出 not_computable/low_quality；返航或偏离航线时不沿用原航线，由E组功能10粗估、B组功能16精算。
- 阈值参数通过项目配置或历史轨迹回放标定；文档中的采样间隔仅为实现初始约束，不作为跨项目固定值。
- 资料与算法边界：OpenSky仅作字段结构参考；MAD用于鲁棒异常判别；球面距离为默认内核，WGS-84 GeographicLib为精度升级路径；均不替代项目接口契约。

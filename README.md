# WaveNest
逐浪智巢（WaveNest）——面向内河在航船舶的低空物流无人机预测式多机巢调度系统。 系统对在航船舶做轨迹预测，动态求解船机会面点，在多机巢间预测式调度无人机，实现"货到即送、船动即调"。 核心能力：船舶状态估计与轨迹预测、船机动态会面求解、飞行中追踪与意图变更检测（船变向即重走上游调度）、返航复核与归巢资源判定、多机巢候选生成与择优、任务监控与可视化大屏。 技术栈：Spring Boot 3.x + MySQL + RabbitMQ + MQTT + Redis；Vue3 + Vite + Leaflet + ECharts + Pinia。 价值：预测式调度替代被动响应、动态会面替代固定航线、货物回收后重派替代空中换机。

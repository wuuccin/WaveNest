# 天地图本地配置

主地图默认使用天地图卫星影像 `img_w` 与影像注记 `cia_w`，可在地图右上角切换到矢量底图 `vec_w` 与矢量注记 `cva_w`。业务坐标保留 WGS-84，只在 Leaflet 渲染层转换为 GCJ-02。

1. 在天地图控制台申请浏览器端密钥，并把本地开发地址加入密钥白名单。
2. 复制 `frontend/.env.example` 为 `frontend/.env.local`。
3. 在 `.env.local` 中填写 `VITE_TIANDITU_KEY=你的密钥`。
4. 重启 Vite。密钥只在本机环境文件中，不能提交。

没有配置密钥时，地图会保持赣江南昌段初始视野并提示缺少配置；不会用网格或虚构地物冒充真实底图。机巢图标只根据 `GET /api/nests` 的有效坐标绘制，且只显示在当前作业区内。
